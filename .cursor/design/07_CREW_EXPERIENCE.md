# Crew Experience

Undruinocpp is a cooperative experience first.

Every gameplay system should reinforce the feeling that the players are members of a real crew rather than individuals playing alongside one another.

The crew is the protagonist.

---

# Every Role Matters

Every crew member should regularly experience moments where they become the most important person on the vehicle.

No role should exist merely to remain occupied.

Every role should occasionally save the expedition.

Players should naturally appreciate one another's contributions.

---

# Interdependence

The strongest crews are not those with the most skilled individuals.

They are those who communicate effectively.

Systems should naturally create interdependence.

The pilot should need Engineering.

Engineering should need Science.

Science should need Navigation.

Weapons should need everyone.

Avoid mechanics that allow one player to consistently solve problems intended for the entire crew.

---

# Shared Ownership

The expedition belongs to the crew.

Victories should feel shared.

Failures should feel shared.

Avoid assigning excessive credit or blame to individual players.

The best stories begin with:

"We..."

rather than

"I..."

---

# Hero Moments

Every expedition should create opportunities for individual heroism.

Examples include:

- repairing a failing system moments before disaster

- making an impossible shot

- discovering an unexpected solution

- sacrificing resources for the team

- making a brilliant navigation decision

- buying enough time for everyone else

Hero moments should emerge naturally rather than through scripted events.

---

# Productive Chaos

The crew should occasionally feel overwhelmed.

Not because systems are unfair.

Because multiple important problems occur simultaneously.

Players should prioritize.

Communicate.

Delegate.

Trust each other.

The solution to complexity should almost always be teamwork rather than individual skill.

---

# Calm Matters

The expedition should include quiet moments.

These are opportunities to:

- admire the landscape

- discuss plans

- repair equipment

- reload

- joke with friends

- tell stories

- discover hidden details

These moments create emotional contrast.

Without calm, tension loses meaning.

---

# Trust

The game should encourage players to trust one another.

Trust another player's expertise.

Trust another player's observations.

Trust another player's judgment.

Players should feel confident handing responsibility to someone else.

---

# Failure Is Collective

Failure should create stories rather than frustration.

Recoverable mistakes are often more memorable than flawless execution.

Allow crews to improvise.

Allow desperate plans.

Allow miraculous recoveries.

Avoid punishing experimentation.

---

# Encourage Conversation

Good crews should naturally talk.

Not because objectives demand it.

Because conversation improves outcomes.

The game should reward sharing information rather than hiding it.

---

# The Best Sessions

The best sessions are those where players leave saying:

"That was incredible."

—not—

"I had the highest score."

Personal achievement should support shared achievement rather than replace it.

---

# Crew Experience Test

When evaluating a new mechanic, ask:

Does this create reasons to communicate?

Does it allow another crew member to shine?

Does it increase trust between players?

Will this create stories that begin with "Remember when we..."

If not, reconsider the mechanic.
